# BM-005: полигональные области

`Region` в `src/domain/region.ts`: `id`, `mapId`, `vertices: {x, y}[]`, `order`, `number`, `title`, `color`, `fillOpacity`. Номер — положительное безопасное целое; название непустое; цвет — hex RGB; непрозрачность 0…1, по умолчанию 0.4. Подпись canvas составляется как «номер. название», отдельный дублирующий label не сохраняется. Поля заметок, Markdown, проверок и тегов вводятся вместе с карточкой в BM-006.

Геометрия — замкнутый простой полигон, заключительное ребро не дублирует первую вершину в массиве. Требуются минимум три различные вершины, ненулевая площадь, конечные координаты. Запрещены пересечения, касания несоседних рёбер и наложение рёбер одного полигона; коллинеарные соседние вершины допустимы без возврата вдоль ребра. Разные области могут полностью перекрываться. Порядок отображения определяется `order`; новые области выше старых. Выбор — по видимому контуру/заливке; навигация для выбора скрытых областей остаётся будущим этапам.

Координаты независимы от изображения и камеры. Stage применяет одну камеру ко всем фигурам. Ввод преобразуется screen→world; перенос контура добавляет одно смещение каждой вершине; перенос ручки меняет только одну вершину. Добавление по ребру проецирует указатель на отрезок. Ручки, толщина выделения и размер подписи остаются постоянными на экране при zoom. Смена картинки сохраняет контуры. После удаления картинки карта и области остаются редактируемыми.

Создание, pointer-preview и drag-preview — временное UI-состояние. Вершины черновика можно перемещать и удалять двойным кликом по ручке, вплоть до пустого контура. Минимум три вершины и валидная геометрия требуются при завершении. Правки черновика не пишутся в базу и историю; они входят в одну операцию создания. Изменение черновика после ошибки записи сбрасывает старый повтор, чтобы не сохранить устаревшие координаты.

Двойной клик использует браузерное событие dblclick. Первый mousedown фиксирует, была ли под указателем существующая ручка: двойной клик по ней удаляет вершину, по фону — добавляет последнюю новую вершину и завершает контур. Второй click с detail=2 не добавляет вершину. Это сохраняет завершение двойным кликом, даже если после первого клика в той точке появилась новая ручка. В режиме правки готовой области двойной клик по ручке выполняет обычную отменяемую команду удаления с минимумом три вершины и проверкой геометрии. Enter/«Готово» валидируют и сохраняют; Esc удаляет черновик. Экспорт читает только сохранённые доменные данные. При ошибке создания вершины сохраняются в памяти; при ошибке изменения прежняя геометрия остаётся в базе, доступен повтор операции. Введённые поля формы сохраняются при отказе применения.

`RegionRepository.save` атомарно заменяет список областей карты и увеличивает Project.revision. Проверяются принадлежность карты/областей, коллизии ID и ревизия. Ошибка любой записи откатывает список и ревизию. `ProjectSession.mutateProject` сериализует команды вместе с изображениями и контекстом; успех публикуется после transaction.oncomplete. Ошибка чтения запрещает изменения, чтобы пустой UI не затёр сохранённые области. Повторное явное открытие даже того же projectId перечитывает карту и области.

`RegionSession` хранит снимки до/после последних 100 завершённых операций. Один drag создаёт одну запись при отпускании; промежуточные положения не пишутся в IndexedDB. Создание, удаление, свойства и правки геометрии поддерживают undo/redo; отмена тоже сохраняется атомарно. Ошибка записи не сдвигает историю. Новая успешная команда очищает redo. При перезагрузке, смене/повторном открытии карты история сбрасывается. Камера, выделение, режим вершин и черновик не входят в историю проекта или архив.

Ограничения редактора: до 2048 областей на карте, до 512 вершин на область, абсолютные координаты до 1e9; допуск различия точек и ненулевой площади — 1e-8. Архив дополнительно ограничивает проект 2048 областями и 65536 вершинами суммарно, а также существующим лимитом JSON 4 МиБ. Эти пределы ограничивают стоимость проверки геометрии непроверенного архива. Области не обязаны попадать внутрь изображения.

Миграция: IndexedDB 2→3 добавляет `regions` с ключом id и неуникальным индексом mapId. Существующие records не переписываются, старые карты получают пустой список областей. Project.schemaVersion остаётся 1: структура Project не изменилась. ZIP v2 добавляет обязательный массив regions; импорт v1 проверяет прежнюю строгую структуру и явно создаёт regions=[] в памяти. ID областей и ссылки mapId переназначаются при импорте вместе с остальными данными; запись копии охватывает regions в той же транзакции. Спецификация: [backup-format.md](backup-format.md).
