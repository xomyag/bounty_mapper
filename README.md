# Bounty Mapper

Рабочее пространство ведущего настольной ролевой игры. Продуктовые требования и порядок задач: [docs/product-design.md](docs/product-design.md).

Реализованы **BM-001 и BM-002**: React + TypeScript + Vite, компактная панель управления, пустая рабочая область карты и локальные проекты в IndexedDB. Через «Проекты» можно создать или открыть приключение; через «Контекст» — изменить название и общие заметки. При перезагрузке восстанавливается последний открытый проект, окна остаются закрытыми. Навигация по объектам пока отключена. Загрузка изображений, pan/zoom, экспорт, области и маркеры относятся к следующим итерациям.

## Требования

- Node.js 24 LTS и npm. Проверено с Node.js 24.21.0 и npm 11.19.0.
- Современный браузер: Chrome, Edge или Firefox.
- Для установки зависимостей нужен доступ к npm registry.

## Запуск

Из корня проекта:

```sh
npm ci
npm run dev
```

Откройте <http://127.0.0.1:5173>. Сервер привязан к локальному интерфейсу; если порт занят, команда завершится ошибкой вместо смены адреса. Остановка — Ctrl+C в терминале.

## Проверки

```sh
npm run typecheck
npm run lint
npm run build
npm test
```

`typecheck` проверяет приложение, тесты и конфигурации; `lint` завершается ошибкой при предупреждениях; `build` проверяет типы и создаёт сборку в `dist/`. `npm test` запускает Vitest: репозиторий IndexedDB проверяется через fake-indexeddb, интерфейс — через Testing Library и jsdom. Эти зависимости нужны только для разработки.

Просмотр готовой сборки:

```sh
npm run preview
```

Откройте <http://127.0.0.1:4173>. Это локальное превью, а не сервер для публикации.

## Ручная приёмка BM-002

1. Откройте приложение: сверху компактная панель Bounty Mapper, ниже пустая рабочая область с текстом «Здесь будет ваша карта».
2. Нажмите «Проекты», введите название и нажмите «Создать». После записи появится «Сохранено на устройстве» и окно контекста.
3. Измените название и контекст; дождитесь автосохранения (задержка 600 мс после ввода) либо нажмите «Сохранить». Статусы: «Есть изменения» → «Сохранение…» → «Сохранено на устройстве».
4. Закройте окно, обновите страницу и откройте «Контекст»: название и текст сохранены; боковая навигация и карточки сами не открываются.
5. Создайте второй проект. Через «Проекты» откройте первый и проверьте его контекст. После перезагрузки должен восстановиться именно выбранный проект.
6. Для проверки ошибки откройте тот же проект во второй вкладке. В первой измените контекст и дождитесь сохранения, затем измените его во второй. Вторая вкладка покажет ошибку конфликта; её текст останется в форме, сообщение об успехе не появится. «Повторить» не затирает чужие изменения. Скопируйте черновик и при необходимости нажмите «Открыть сохранённую версию» с явным подтверждением замены.
7. Сузьте окно до 375 px, проверьте Tab/Enter и закрытие окна через Esc. Проверьте консоль браузера на ошибки.

Ошибка квоты, отказ записи и отмена транзакции проверяются автотестами. Черновик сохраняется в памяти открытой страницы после ошибки, а не на диске; переход к другому проекту блокируется до сохранения. При попытке перезагрузки с несохранёнными данными браузер получает запрос на предупреждение.

## Локальное хранение

Данные привязаны к адресу приложения и профилю браузера. Используйте один адрес <http://127.0.0.1:5173>; `localhost`, другой порт и превью на 4173 имеют отдельные базы. Очистка данных браузера удаляет проекты. Архивирование и работа без сети будут реализованы позднее.

Схема IndexedDB и формат Project впервые введены в версии 1. В базу записываются название, контекст, стабильный ID, revision и даты; последний открытый ID хранится отдельно от документа. Хранилища для Map и Asset предусмотрены, но в BM-002 они пусты: карта и загрузка изображений пока не создаются. Подробнее: [docs/storage.md](docs/storage.md).

## Структура

```text
src/main.tsx       точка входа React
src/App.tsx        стартовый экран
src/styles.css     оформление и адаптивность
src/domain/        модели Project, Map, Asset
src/application/   контракт репозитория и состояние редактирования
src/storage/       IndexedDB и проверки транзакций
src/features/projects/ окна создания, выбора и контекста
docs/             продуктовый документ
AGENTS.md         правила разработки
```

Редактор карты добавляется в следующих BM-задачах. Версии пакетов фиксируются в `package.json` и `package-lock.json`; для воспроизводимой установки используйте `npm ci`.
