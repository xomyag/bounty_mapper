# Bounty Mapper

Рабочее пространство ведущего настольной ролевой игры. Продуктовые требования и порядок задач: [docs/product-design.md](docs/product-design.md).

Реализован **BM-001**: основа React + TypeScript + Vite, компактная панель управления и пустая рабочая область карты. Навигация и карточки закрыты; демонстрационных объектов нет. Кнопки «Проект» и «Навигация» пока отключены, подсказки объясняют причину. Создание проектов, загрузка изображений, pan/zoom, хранение, экспорт, области и маркеры относятся к следующим итерациям.

## Требования

- Node.js 24 LTS и npm. Проверено с Node.js 24.21.0 и npm 11.19.0.
- Современный браузер: Chrome, Edge или Firefox.
- Для установки зависимостей нужен доступ к npm registry.

## Запуск

Из корня проекта:

```sh
npm ci
npm run dev
```

Откройте <http://127.0.0.1:5173>. Сервер привязан к локальному интерфейсу; если порт занят, команда завершится ошибкой вместо смены адреса. Остановка — Ctrl+C в терминале.

## Проверки

```sh
npm run typecheck
npm run lint
npm run build
```

`typecheck` проверяет приложение и конфигурацию Vite; `lint` завершается ошибкой при предупреждениях; `build` проверяет типы и создаёт сборку в `dist/`.

Просмотр готовой сборки:

```sh
npm run preview
```

Откройте <http://127.0.0.1:4173>. Это локальное превью, а не сервер для публикации.

## Ручная приёмка BM-001

1. Откройте приложение: сверху компактная панель Bounty Mapper, ниже пустая рабочая область с текстом «Здесь будет ваша карта».
2. Убедитесь, что боковая навигация, карточки и демонстрационные объекты отсутствуют. Кнопки будущих функций отключены.
3. Обновите страницу: стартовое состояние не меняется.
4. Сузьте окно до 375 px: панель переносится, текст и рабочая область остаются доступны без горизонтальной прокрутки.
5. Нажмите Tab: ссылка Bounty Mapper получает видимый фокус; Enter переводит к рабочей области.
6. Проверьте консоль браузера на ошибки. Повторите сценарий через `npm run preview` после сборки.

Автотесты поведения будут добавляться вместе с логикой следующих задач. Для статического стартового экрана используются сборка, проверка типов, lint и ручная приёмка.

## Структура

```text
src/main.tsx       точка входа React
src/App.tsx        стартовый экран
src/styles.css     оформление и адаптивность
docs/             продуктовый документ
AGENTS.md         правила разработки
```

Доменные модели, хранилище и редактор добавляются по мере реализации соответствующих BM-задач. Версии пакетов фиксируются в `package.json` и `package-lock.json`; для воспроизводимой установки используйте `npm ci`.
